##
Cada módulo tenga su propio routing (muy recomendado):
  ng generate module features/dashboard --routing

Esto crea un componente reutilizable para mostrar métricas clave, como clientes activos, balance y pagos.
  ng generate component features/dashboard/components/resumen-kpis

Sección de clientes:
  ng generate service core/services/clientes

Crea un módulo independiente para autenticación (auth), que contendrá el componente de login y sus servicios.

  xxx => ng generate module auth --route login --module app.module.ts
  xxx => ng generate component auth/login

Esto crea:

  xxx => auth/auth.module.ts — módulo de autenticación con lazy loading configurado.
  xxx => auth/login/login.component.ts — componente Login

- DOMAIN:
  - MODELO: ng g interface domains/clientes/domain/cliente --type=model
  - ENTIDAD: ng g interface domains/clientes/domain/cliente --type=entity
  - REPOSITORIO (CONTRATO): ng g interface domains/clientes/domain/cliente-repository
- APPLICATION:
  - ng g service domains/clientes/application/create-cliente --skip-tests
  - ng g service domains/clientes/application/get-clientes --skip-tests
  - ng g service domains/clientes/application/update-cliente --skip-tests
  Luego renombramos manualmente:
  create-cliente.service.ts → create-cliente.usecase.ts
  get-clientes.service.ts → get-clientes.usecase.ts
  update-cliente.service.ts → update-cliente.usecase.ts
- INFRAESTRUCTURE:
  - ng g service domains/clientes/infrastructure/cliente-api --skip-tests
  - ng g service domains/clientes/infrastructure/cliente-repository-impl --skip-tests
- UI:
  PARA LISTAR :
    ng g component domains/clientes/ui/pages/list-clientes \
    --standalone \
    --change-detection OnPush \
    --style scss \
    --skip-tests

    Renombrar a:  list-clientes.page.ts

  PARA CREAR :
    ng g component domains/clientes/ui/pages/create-cliente \
    --standalone \
    --change-detection OnPush \
    --style scss \
    --skip-tests

    Renombrar a:  create-cliente.page.ts

  RUTAS:
    Crear manualmente
      src/app/domains/clientes/clientes.routes.ts
