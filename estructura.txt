##
Cada módulo tenga su propio routing (muy recomendado):
  ng generate module features/dashboard --routing

Esto crea un componente reutilizable para mostrar métricas clave, como clientes activos, balance y pagos.
  ng generate component features/dashboard/components/resumen-kpis

Sección de clientes:
  ng generate service core/services/clientes

Crea un módulo independiente para autenticación (auth), que contendrá el componente de login y sus servicios.

  xxx => ng generate module auth --route login --module app.module.ts
  xxx => ng generate component auth/login

Esto crea:

  xxx => auth/auth.module.ts — módulo de autenticación con lazy loading configurado.
  xxx => auth/login/login.component.ts — componente Login
